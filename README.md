# Skystore — Интернет-магазин на Django

Веб-приложение для управления каталогом товаров и категорий, разработанное в рамках выполнения лабораторных работ.

## Стек технологий
- **Backend:** Python 3.14+ / Django 6.1
- **Database:** PostgreSQL (с автоматической локальной поддержкой SQLite3 для быстрой проверки)
- **Драйвер БД:** psycopg v3
- **Frontend:** HTML5, CSS3 (Автономная адаптивная сетка Bootstrap)
- **Зависимости:** Pillow (работа с медиаданными), IPython (интерактивный shell)

## Выполненные требования (Критерии оценки)

### Архитектура и База данных
- Настройки подключения к СУБД полностью вынесены в переменные окружения (`.env`).
- Создан демонстрационный шаблон конфигурации `.env.sample`.
- Все служебные файлы PyCharm (`.idea/`), кэш-файлы (`__pycache__/`) и файлы баз данных (`db.sqlite3`) добавлены в `.gitignore` и исключены из репозитория.

### Контроллеры и Маршрутизация
- Реализован лаконичный вывод списка всех товаров на главной странице через `Product.objects.all()`.
- Настроена детальная страница товара с динамическим URL вида `/products/<int:pk>/` и неймингом `product_detail`.
- Реализована форма создания нового товара с валидацией обязательных полей, CSRF-защитой и сохранением данных в БД.
- Настроены удобные переходы с главной страницы на детальную страницу товара и обратно.

### Шаблонизация (MVT)
- Выделен общий базовый шаблон `base.html`, содержащий общие стили, разметку, шапку и подвал сайта.
- Создан и подключен во все шаблоны изолированный подшаблон главного меню навигации (`inc_nav.html`).
- Описание товаров в карточках каталога обрезается до **100 символов** с помощью фильтра шаблонизатора (`truncatechars:100`).
- Настроена корректная обработка и раздача медиаданных (`MEDIA_URL`, `MEDIA_ROOT`) в режиме `DEBUG`.

### Фикстуры и Кастомные команды
- Сформированы эталонные фикстуры данных для моделей `Category` и `Product` в кодировке `UTF-8`.
- Реализована кастомная management-команда `python manage.py fill_db`, которая перед наполнением базы автоматически очищает старые записи в правильном порядке (защита от ошибок связанных ключей).

## Инструкция по развертыванию и запуску

### 1. Клонирование репозитория и настройка окружения
```bash
git clone https://github.com
cd my_django_project
python -m venv .venv
source .venv/bin/activate  # Для Linux/macOS
.venv\Scripts\activate     # Для Windows
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте в корне проекта файл `.env` на основе шаблона:
```bash
cp .env.sample .env
```
Заполните параметры подключения к вашей локальной СУБД PostgreSQL. Если вы хотите запустить проект на SQLite3, укажите в `.env`:
```text
LOCAL_SQLITE=True
```

### 4. Наполнение базы данных тестовыми данными
Выполните кастомную команду для очистки таблиц и загрузки фикстур:
```bash
python manage.py fill_db
```

### 5. Запуск сервера разработки
```bash
python manage.py runserver
```
Приложение будет доступно по адресу: [http://127.0.0](http://127.0.0)
